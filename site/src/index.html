A few more things it does

  • {{icon terminal-window}}

    Quit the app and your threads keep going

    A separate little process called the runner owns the agents, so closing, quitting or updating the app never stops a turn.

  • {{icon link}}

    Every thread has its own link

    Open a thread on the web from its menu, then copy its link to open in any browser you're signed in on, or paste it to yourself for later.

  • {{icon desktop}}

    Schedules that run on any of your Macs

    Send a thread a message at a set time, once or over and over, or start a new thread each time. Pick which Mac it runs on and it runs there, even while this one's asleep.

  • {{icon key}}

    Runs on your own Claude or Codex login

    It drives the official claude and codex command line tools, logged in as you, so it's your plan doing the work. It never reads or copies your login tokens.

Install it with a prompt

There's nothing to download. You paste this into Claude Code or Codex and your agent sets it all up for you.

  • A Mac with Apple silicon
  • Claude Code or Codex
  • A Convex account
  1. Copy the promptIt's printed in full here, so you can read exactly what it asks for.
  2. Paste it into Claude Code or CodexYour agent forks the repo and checks the code for anything malicious before it runs any of it, then tells you what it thinks.
